GAU archive providers

GAU · Archive discovery

Balanced avoids repeated slow archive lookups for hosts with no historical results. Expanded includes Common Crawl, with independent timeouts and cooldowns. A zero-result archive query does not prove that the host has no endpoints.

Query reference comparisons

IDOR-Forge · limited GET profile

Use explicit reference IDs you are authorized to test. This keyless, anonymous profile sends at most four GET requests to one path and never follows redirects. Configure one selected asset at a time. Without these inputs the module skips.

Similarity is a review signal. This profile cannot prove object ownership or missing authorization; verify candidates using two authorized test accounts. Credentials, mutations, broad payload fuzzing and the upstream GUI are outside this profile. Reference values and response bodies are omitted from results and logs.

Optional module inputs

Optional inputs stay in this job's memory. Source/SBOM content is not included in saved results. Attach artifacts to one selected asset at a time. Full pipeline skips tools whose inputs are absent.

Optional: runs TruffleHog’s built-in verification for all detector types against the original supplied source. Native detectors use the credential and its source context to check the relevant service, which can include a database or another host. No five-provider restriction or 10-candidate cap. One worker, with a 120-second overall process limit on HF. Some detectors may be unable to verify, skip verification or encounter network errors; an unverified result never proves a secret is invalid. Values, account details and provider errors are redacted. Full pipeline does not enable this option.

Nuclei · Template selection

Combine any bundled profiles, compatible community templates, and custom YAML. This selection applies to new scans only. Community and custom templates must pass the server's GET/HEAD-only validation; dynamic DSL, POST requests, remote interactions, and unsafe paths are blocked.
